Simple eyes exercises for tired eyes. 
Lately I was working a lot by the screen while developing Acupuncturist game (https://nodemd.itch.io/acupuncturist) so in the meantime I made those short eyes exercises to give my eyes a break. 
Maybe they will be helpful for you too.

Works best in FullScreen mode.

It is open source: https://github.com/nodeMD/eyes-exercises so if you would like to edit those exercises or add more feel free to do so by forking this repository.
